# DQ03: attrition

A black form tips its way across a white field, and every landing costs it a piece of itself. The pauses grow longer, the camera draws back to show the trail, and it ends mid effort with about two thirds left. Made from code in under 4kb.

[Run it](https://deadquiet42.github.io/dq03/), or open `dq03.html` in a browser and click. It plays full screen with sound.

## Build

```
npm install
npm run build
```

`dq03-source.js` is the readable source. The build minifies it with terser and packs it with roadroller into `dq03.html`.
